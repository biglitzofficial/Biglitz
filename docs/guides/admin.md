# Admin guide (one page)

You manage the business units assigned to you.

**People → + New:** enter name, mobile, a temporary PIN, unit, manager, joining date, salary, bank details and the last 4 digits of Aadhaar. The employee ID is generated automatically (year + unit code + running number). The person stays *pending* until you **upload both Aadhaar sides** (employee page → Documents) and tap **Activate**.

**Employee page:** edit details (a reason is required and recorded), upload other documents (add a remark), reset a PIN, add a **salary advance**, or **Record exit**. After the exit date the person cannot log in, and open leads must be reassigned.

**Business units (More):** set the shop's GPS location (stand in the shop and tap "Use my current location", radius 100-200 m), default shift, sales categories (amount or count), holidays, and the lead "Lost" reasons.

**Payroll (monthly)**
1. On the 1st the draft for last month is created automatically (or tap *Create draft*).
2. Check each line (tap to expand: days, advance recovery, adjustments, incentive). Add adjustments with a reason. Missing bank details block the bank CSV, so fix them before the payment step.
3. **Submit** salary (paid around the 5th) and incentive (paid around the 10th) separately.
4. The Super Admin (or an Admin with approval rights) approves. Approving **locks the month**.
5. Download the **bank CSV**, pay, then tap **Mark as paid**. Payslip PDFs appear for staff after both parts are approved.

**Reports:** payroll cost per unit, attendance trend, discipline ranking, sales by category, and the leads funnel.

Every number on the dashboards opens the list behind it.
